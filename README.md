# Smart Bin

Учебный прототип для сортировки бытовых отходов по тексту и фотографии.

## Запуск локально

1. Установите Python 3.10 или новее.
2. В терминале из этой папки выполните:

   python -m pip install -r requirements.txt
   
   python -m streamlit run app.py

Модель для распознавания изображений скачивается при первом запуске фото-классификации; для неё нужен доступ в интернет.

## Публикация через Streamlit Community Cloud

1. Создайте публичный репозиторий GitHub и загрузите в него файлы проекта.
2. Откройте https://share.streamlit.io/ и войдите через GitHub.
3. Выберите репозиторий, ветку main, файл app.py, затем нажмите Deploy.

База waste.db в репозиторий не включается: история пользователей остаётся локальной. На бесплатном облачном запуске локальная SQLite-база создаётся заново и не является постоянным хранилищем.

## Ограничения

Это учебный прототип, а не сертифицированная система сортировки. Проценты нейросети не являются измеренной точностью. Электронные устройства и батареи контейнер Smart Bin не принимает — их следует сдавать отдельно.
